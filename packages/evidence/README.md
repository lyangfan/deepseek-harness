# evidence/ — deterministic scientific Evidence family

English | [中文](README.zh.md)

This family turns authoritative DSH runtime records into validated, immutable scientific Evidence projections. It does not replace the Session log, Tool runtime, or Storage Domain owner.

| Package | Role | `ctx` key |
|---|---|---|
| [`evidence-core/`](evidence-core/README.md) | Deterministic Session-event capture, immutable Snapshot publication, recovery, GC, and exact export | none (private function plugin) |

The [Evidence subsystem reference](../../docs/subsystems/evidence.md) describes the data flow and authority boundary.
